Network Layer Recovery v1.1.0

QGIS 3.22–4.99QGIS 4 / Qt6Experimental

Reopens file-based layers on network drives after Windows sleep/hibernate, so rasters render and vectors become editable again without restarting QGIS.

More

When a project is opened from an SMB share / mapped network drive and the PC sleeps, the GDAL/OGR handles held by QGIS go stale. Even after Windows reconnects the share, some rasters fail to render and some vector layers cannot be edited. This plugin detects system resume (Windows power notifications plus a wall-clock gap fallback), waits until the network shares are reachable again (probing in a background thread so QGIS never freezes) and then reopens the data provider of every affected layer. Layers in edit mode are never touched automatically. A manual "Recover network layers" command and a "Recover selected layers" command are also provided.

QWebMap v4.58.11

Fork of GallPeters/QGIS2VectorTiles · 699 commits aheadQGIS 3.44–4.99QGIS 4 / Qt6

Publish a QGIS project as a fast web map that keeps its QGIS look: most QGIS symbology (patterns, SVG icons, marker lines, dashes, labels) is converted accurately to vector tiles, with a full web viewer and one-click publishing to Cloudflare R2 or other S3-compatible storage.

More

QWebMap turns a QGIS project into a public web map that looks like it does in QGIS. Its core is an accurate converter of QGIS symbology to vector tiles and a MapLibre style: categorized, graduated and rule-based renderers, hatches, point/SVG pattern fills, gradient and shapeburst fills, marker lines at the QGIS positions, dashes, arrows, SVG and font markers, and labels in your own fonts; most of what the browser cannot draw natively is rendered by QGIS into sprites or pre-computed geometry, the rest is approximated or left out, and every export writes a fidelity report. Its Publish Web Map window builds vector tiles in one PMTiles archive (QGIS-accurate styling: marker-line positions, patterns, dashes, labels, with a fidelity report), raster layers as image tiles, an optional OpenStreetMap vector basemap or web (XYZ) basemaps, map themes as views and a full modern viewer (layers, legend, popups, search, filters, permalinks, measuring with snapping, printing). It publishes with verification to Cloudflare R2 or other S3-compatible storage at a stable address, and keeps all settings in the project. No map server needed. QWebMap is developed by Ábel Kőszeghy. It started as a fork of QGIS2VectorTiles by Jossef Kanter (https://github.com/GallPeters/QGIS2VectorTiles), whose converter is still its foundation; its Processing tool still exports a static vector tile package.

Topological Paste v1.0.1

QGIS 3.28–4.99QGIS 4 / Qt6

Paste clipboard features into the active layer with overwrite semantics: pasted coverage wins, existing features underneath are trimmed (not duplicated), everything as one undoable edit.

More

Pastes the geometries and attributes on the QGIS clipboard into the active vector layer. Pasted features take priority: their coverage is cut out of the existing features underneath, existing features are deleted only when nothing of them remains, surviving portions keep their attributes, identical geometries are reused instead of duplicated, shared boundaries are consistently noded, and the whole operation is a single Undo step. A preview is shown before anything is changed. Works with polygons (main use case: cadastral / zoning layers), lines and points. Requires no external Python packages.

Virtual Layer Guard v0.1.0

QGIS 3.30–4.99QGIS 4 / Qt6Experimental

Prevents QGIS from silently dropping virtual (and other dependent) layers from the project file.

More

If any layer of a project depends on a layer ID that no longer exists (for example after deleting or replacing a layer, changing data sources, or moving layers between projects), QGIS skips EVERY layer that has a dependency while loading the project, without an error message. Virtual layers always have dependencies. The skipped layers keep their name in the Layers panel, and the next save removes their definition from the project file for good. This plugin removes dependencies on missing layers on every save, keeps definitions QGIS would drop, restores skipped layers automatically when a project is opened, keeps a copy of every virtual layer definition for later recovery, and warns when removing a layer or changing its data source breaks a virtual layer. The user interface is English or Hungarian, following the QGIS language.

Cross-Instance Layer Drag v0.2.0

QGIS 3.22–4.99QGIS 4 / Qt6Experimental

Keeps layer IDs and copies memory-layer features when dragging layers between two running QGIS instances.

More

When a layer is dragged from the Layers panel of one QGIS process to another, QGIS assigns a new layer ID and memory (temporary scratch) layers arrive empty. This plugin intercepts such drops: the original layer ID is kept unless it already exists in the target project (then only that layer gets a new ID and references are rewritten), and memory-layer features, including unsaved edits, are copied through a temporary GeoPackage snapshot. Groups, styles and layer settings are transferred as well. Works when dropping on the Layers panel or on the map canvas. Install and enable it in BOTH QGIS instances. The user interface is English or Hungarian, following the QGIS language.
